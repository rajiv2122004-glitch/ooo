# Gain Grub
Static site (HTML/CSS/JS, no build step). Host on GitHub Pages.

1. Create a repo, upload everything in this folder (keep `assets/`).
2. Settings > Pages > Deploy from branch > `main` / root.
3. Site goes live at https://YOUR-USER.github.io/REPO/

Booking form opens the visitor's email app addressed to chandu@gmail.com.
